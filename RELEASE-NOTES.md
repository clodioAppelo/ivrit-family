# Ivrit Family — Level & Skills Edition

This update preserves the existing guided modules (44), conversation practice (120 phrase items), handwriting, alphabet, gender and placement test. It adds a **Personal Skill Studio** where every learner independently chooses A0/A1/A2/B1/B2 and practices listening, reading, writing and speaking using the available modules at that level. Progress is saved separately per learner on each device.

## Publishing on GitHub Pages
Upload the contents of this folder into the root of the existing `ivrit-family` repository. Replace same-name files, including `index.html` and `sw.js`, and commit. Wait for GitHub Pages deployment. Check the Skills tab on Safari and the installed Home Screen app.

## Honest limitations
This is **not a complete proficiency-certified A0–B2 course**. The 44 modules are short and higher levels have limited depth. Listening uses synthesized Hebrew voices; speaking uses optional browser speech recognition, which cannot score phonetic accuracy reliably and may be unavailable on iPhones. Writing checks exact normalized text rather than open-ended composition. Handwriting uses an online font. Progress is local, not synced between devices. For full speaking/writing/listening proficiency, a larger graded curriculum, authentic recordings, human/AI assessment and feedback are still required.
