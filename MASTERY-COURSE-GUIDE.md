# Ivrit Family — Hebrew Mastery Curriculum

## Scope
70 authored, level-tagged instructional units: 10 per level A0, A1, A2, B1, B2, C1, C2. Each has a Hebrew model sentence, English and Spanish meaning, instructional focus, and independent production challenge. The existing app course and skill studio remain available.

## Learning cycle
Choose profile → select level and unit → listen without text → read aloud → write from translation → compare → complete production challenge → mark correct or practice again → review due items. Progress is stored per profile in the browser. Export a JSON backup from the Mastery tab.

## Assessment limitations
A learner marking an item correct is self-report, not validated mastery. Writing checks exact model text, not creative answers. Speaking practice uses speech synthesis for modeling and self-evaluation; it does not grade pronunciation. Text-to-speech voice availability varies. The 70 units are a substantial structured expansion, **not a complete C2 curriculum or accredited proficiency assessment**. A complete program would require thousands of additional contextual examples, extensive natural recorded listening, teacher-reviewed writing and speaking, and longitudinal validation.

## Installation
Extract ZIP and upload index.html, master-curriculum.js, master-curriculum.json, sw.js, manifest.webmanifest, and icons/ into the root of the existing GitHub Pages repository. Preserve file names and directory structure. Wait for deployment and reload. Do not clear browser website data without exporting progress.

## Privacy
Profiles are local to each browser/device. Exported JSON contains learner name and practice record; keep it private. No online account sync.
